# Borrowboard · 邻里借用

上架 → 借出通过 → 归还；单物件同时仅一笔在借，含逾期判定。

逾期一律按设置中保存的**业务日**（`business_date`）现算，不看机器当天；改业务日只重新划分在借/逾期，不改 `items.status`、不把在借物挪回可借栏。非法业务日（非严格 `YYYY-MM-DD`）保存返回 400，设置与逾期判定维持改前。

| 前端 | 5400 |
| API | 10400 |

0-1：`deposit` / `damage_note` / `neighbor_rating`。
